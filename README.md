# Tea Heaven Order

Smart online ordering website for Tea Heaven Cafe.

## Run locally
Open `index.html` in a browser, or use a static server.

## Deploy (GitHub Pages)
1. Create repo `tea-heaven-order` under `alasastrixie6-boop`.
2. Upload all files keeping structure.
3. Settings → Pages → Deploy from branch `main` / root.
4. Visit https://alasastrixie6-boop.github.io/tea-heaven-order/

Note: localStorage is per-browser demo; not shared across devices.
