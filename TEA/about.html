About Tea Heaven Order

This project provides a smart online ordering website for Tea Heaven Cafe to reduce lines and process orders fairly using FIFO.

Mission

Faster, fairer, fresher service.

FIFO for Orders

The first eligible order received is prepared before later waiting orders. Stable sequence numbers and timestamps ensure consistent ordering.

FIFO for Ingredients

Oldest eligible ingredient batch is used first (receipt date, then batch ID). Expired stock is never used.

Benefits

  • Customers: shorter waits, clear prices, order tracking.
  • Staff: organized queue, inventory alerts.
